# Fritz Laplage Shopping

A sign-up form project inspired by **The Odin Project – Intermediate HTML & CSS** curriculum.

## About the Project

This project is a custom sign-up page designed for **Fritz Laplage Shopping (FLS)**, a 100% online fashion and accessories shop.

The page combines a two-column layout with:

* A branded image sidebar
* FLS logo and branding
* Customer registration form
* HTML form validation
* Custom typography
* Focus and validation states for form inputs
* Responsive-ready CSS structure

## Technologies

* HTML5
* CSS3
* Git
* GitHub
